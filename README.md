# Knowledge Browser

Knowledge Browser is a clean product repository for ACL-safe company knowledge
search across Slack, Jira, Confluence, and GitHub-shaped data.

This repository is being rebuilt from approved feature contracts. Each feature
is added through one focused pull request and squash-merged into `main`.

See:

- `docs/PRODUCT_INTENT.md` for product guardrails.
- `docs/contracts/FEATURE_CONTRACT_TEMPLATE.md` for feature requirements.
- `docs/superpowers/specs/2026-08-31-clean-product-migration-design.md` for the migration design.
